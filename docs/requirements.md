# RUN TERRITORY 요구사항 분석

## 1. 프로젝트 목표
사용자가 실제 러닝을 통해 GPS 경로를 기록하고, 폐곡선으로 만든 면적을 영토로 등록하며, 캐릭터와 랭킹 요소를 통해 지속적인 참여와 활동을 유도하는 위치 기반 러닝 게임을 구현한다.

## 2. 핵심 기능
1. GPS 러닝 및 영토 등록
2. 캐릭터 뽑기 및 강화
3. 땅 자연 감소
4. 개인 랭킹

## 3. 사용자 흐름
로그인 → 러닝 시작 → GPS 경로 기록 → 러닝 종료 → 면적 계산 → 포인트 획득 → 영토 등록 → 캐릭터 성장 → 랭킹 확인

## 4. 기능별 요구사항
### GPS 러닝 & 영토
- 사용자는 러닝을 시작/종료할 수 있어야 한다.
- 서버는 러닝 경로를 저장할 수 있어야 한다.
- 폐곡선이 완성되면 면적을 계산할 수 있어야 한다.
- 계산된 면적은 영토로 등록되어야 한다.

### 캐릭터
- 사용자는 포인트로 캐릭터를 뽑을 수 있어야 한다.
- 사용자는 보유 캐릭터를 조회할 수 있어야 한다.
- 사용자는 포인트를 사용해 캐릭터를 강화할 수 있어야 한다.

### 땅 자연 감소
- 일정 기간 활동이 없으면 영토 점령력이 감소해야 한다.
- 점령력이 0이 되면 중립화되어야 한다.

### 랭킹
- 사용자는 보유 면적 랭킹을 확인할 수 있어야 한다.
- 사용자는 누적 거리 랭킹을 확인할 수 있어야 한다.

## 5. 비기능 요구사항
- .env 파일은 GitHub에 올리지 않는다.
- API는 앱과 서버가 동일한 명세를 기준으로 개발한다.
